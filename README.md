# 뭉치 AI (MoongCheap AI)

수요 주도형 공동구매 플랫폼의 AI 파트 저장소입니다.

## AI 핵심 기능

1. **소비자 수요 클러스터 생성**
   - 소비자 데이터를 Embedding하여 유사 수요를 Cluster로 구성
   - Vector DB 기반 검색을 기본으로 사용
   - 필요할 때 카테고리, 가격, 수량, 상품 속성 등 정형 조건을 결합한 Hybrid 방식 적용

2. **수요 Cluster–판매자 매칭**
   - 수요 Cluster와 판매자 Offer를 비교하여 적합한 판매자 후보 탐색
   - Embedding 기반 후보 검색 후 필요 시 Filter, Scoring, Ranking 결합
   - 최종 매칭을 LLM의 임의 판단에 맡기지 않음

3. **판매자용 소비자 수요 분석**
   - 주요 요구조건, 선호 가격대, 수요 규모, 조건별 분포, 공통 특징 분석
   - 판매자 관점의 메리트, 디메리트/리스크, 고려사항 제공
   - 수치와 사실은 실제 데이터 집계 결과를 사용하고, LLM은 필요한 경우 자연어 설명을 담당

4. **매칭 이후 소비자용 RAG 챗봇**
   - 매칭된 판매자의 상품 및 판매조건 문의 응답
   - 지식 소스는 해당 판매자가 제공한 정보로 제한
   - 근거가 없는 내용은 생성하지 않고 확인 불가로 응답하는 Abstention 적용

## Scope

소비자/판매자 자연어 처리 및 LLM 핑퐁은 현재 핵심 기능 범위가 아닙니다. Consumer/Seller 최종 Schema는 백엔드가 제공하는 계약을 사용합니다.

Qwen3-8B-AWQ, vLLM 상시 서빙 등 특정 모델·인프라 구성은 확정하지 않으며, 네 가지 기능의 요구사항과 평가 결과에 따라 결정합니다.

프론트엔드, 백엔드, 클라우드/인프라는 각 담당 파트에서 관리합니다.

## Repository structure

- `apps/ai`: AI 서비스 구현
- `docs`: AI 설계, 인터페이스, 평가 기준 및 실험 문서
- `.github`: PR/이슈 템플릿 및 협업 설정

## Development workflow

1. `main`에서 작업 브랜치를 생성합니다.
2. 작은 단위로 커밋합니다.
3. Pull Request를 생성합니다.
4. 작성자가 아닌 팀원 1명의 승인과 검증 통과 후 `main`에 squash merge합니다.

자세한 규칙은 [CONTRIBUTING.md](CONTRIBUTING.md)를 참고하세요.
